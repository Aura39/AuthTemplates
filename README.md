# AuthTemplates
This repository hosts community-made templates for AuthEdit  

## Contributing
You have 2 options for contributions:
- Ping @aura6633 on Yakuza Modding Community with a zip file of all templates, specifying what game they're for and who made every template. (if some templates aren't made by you)
- Submit a Pull Request on GitHub. (if you know how to do that)

Contribution rules:
- Only submit templates that you have permission to share, or templates that you have permission to share.
- Do not contribute broken or misleading templates (i.e. misnamed properties), unfinished templates are fine.

## Usage
1. Download the zip of the repo (Code -> Download ZIP)
2. Drop everything from the `templates/` folder into the `config/game/` folder of your AuthEdit copy.
